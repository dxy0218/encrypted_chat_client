# Encrypted Chat Apple v0.01beta

SwiftUI client skeleton for iOS 18.0+, iPadOS 18.0+, and macOS 15+.

## Open in Xcode

1. Open this folder in Xcode 16 or newer.
2. Create an iOS App target if Xcode opens the package as a library only.
3. Add the files under `Sources/EncryptedChatApple` to that app target.
4. Set the deployment target to iOS 18.0 or iPadOS 18.0.

The current Apple client provides the UI shell, identity verification flow, relay
settings, and transport status model for v0.01beta. Full protocol parity with
the Python desktop client is planned after the desktop protocol stabilizes.
